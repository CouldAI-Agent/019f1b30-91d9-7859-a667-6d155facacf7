# Binance Trading Community Landing Page

A premium, modern, and luxurious landing page designed for a Binance Trading Community. Built with Flutter, the app features a professional fintech appearance inspired by top cryptocurrency platforms. 

## Features
- **Hero Section**: Live chart mockup, floating crypto coins, and premium CTAs.
- **Top Statistics**: Animated glassmorphism cards tracking members, volume, and assets.
- **Membership & Pricing**: Detailed tier comparisons with gold accents.
- **Market Dashboard**: Live price tracking and market heatmaps.
- **Why Join Us**: Professional insights and educational resources.
- **Responsive Layout**: Designed for mobile, tablet, and desktop with a deep dark theme and neon gold highlights.

## Tech Stack
- Flutter
- Google Fonts (Inter)
- Supabase (ready for integration)

## Run Instructions
1. Ensure Flutter 3.7.2 or later is installed.
2. Run `flutter pub get` to fetch dependencies.
3. Start the app on your preferred platform: `flutter run`
